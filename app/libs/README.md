Put an FFmpegKit Android AAR here (e.g. `ffmpeg-kit-full-gpl-6.0-2.aar`).
The official com.arthenica artifacts were removed from Maven Central, so grab one from a community
fork's releases or build your own (https://github.com/arthenica/ffmpeg-kit). Use a "full" build so
libmp3lame, libvorbis, libvpx and libopus are available.
